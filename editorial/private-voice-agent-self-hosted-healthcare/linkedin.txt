"Where does the patient's voice go?"

That one question stalls most voice agent pilots in Canadian healthcare. A cloud region dropdown does not answer it. Three vendors still see every call: speech to text, the model, and the voice.

So we built a check-in line for a fictional hospital where all three run on one GPU server we control:
→ faster-whisper for speech to text, served by speaches
→ Qwen3-4B on vLLM for the model and its tool calls
→ Kokoro-82M for the voice
→ one HTTPS endpoint, one key, LiveKit's OpenAI plugin pointed at it

The part buyers care about: every model client goes through a transport that counts bytes by host. The panel shows the result live. Zero bytes to AI providers.

It is not free. Whisper waits until you stop talking, so speech to text is slower than streaming cloud STT. The GPU bills by the hour whether anyone calls. Someone has to run it. The demo shows the latency next to the cloud numbers so you can judge.
