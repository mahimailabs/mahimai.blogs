# Sources

- speaches (https://speaches.ai): OpenAI-compatible server for faster-whisper STT and Kokoro TTS; Docker image tag, API_KEY, PRELOAD_MODELS and model TTL settings, Kokoro model id.
- vLLM tool calling (https://docs.vllm.ai/en/latest/features/tool_calling.html): --enable-auto-tool-choice and the hermes parser for Qwen models.
- Qwen3-4B-Instruct-2507 (https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507): the non-thinking instruct model used for the LLM.
- faster-whisper large-v3 turbo CT2 (https://huggingface.co/deepdml/faster-whisper-large-v3-turbo-ct2): STT model id.
- Kokoro-82M (https://huggingface.co/hexgrad/Kokoro-82M): parameter count and Apache 2.0 licence.
- LiveKit self-hosting (https://docs.livekit.io/home/self-hosting/deployment/): self-hosted media server for the deployment layout.
- Nova Scotia PIIDPA FAQ (https://novascotia.ca/just/iap/piidpaquest.asp): public bodies store and access personal information only in Canada, with exceptions.
- Quebec Law 25 (https://cloud.google.com/security/compliance/quebeclaw25): privacy impact assessment before communicating personal information outside Quebec. Secondary source; check the statute or CAI guidance before quoting further.
- LiveKit Agents 1.8.5 openai plugin source (installed package): STT use_realtime, TTS handling of raw-audio responses from OpenAI-compatible servers, provider = base URL host.
- Cloud comparison figures: mahimai.ca src/data/latency.json (Mahimai estimates, 2026-08), shown as estimates.
