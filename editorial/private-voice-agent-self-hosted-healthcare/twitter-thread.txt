1/ "Where does the participant's voice go?" kills voice agent pilots at Canadian research hospitals. A region dropdown doesn't answer it. So we built a clinical trial check-in line where STT, LLM and TTS all run on one GPU server we control.

2/ The stack: faster-whisper (speaches) for STT, Qwen3-4B-Instruct on vLLM for the model, Kokoro-82M (speaches) for the voice. One Caddy endpoint, one bearer key. Fits on a 24 GB GPU.

3/ No custom LiveKit plugins. The OpenAI plugin talks to any OpenAI-compatible server. Set use_realtime=False for Whisper, response_format="pcm" for Kokoro, and pass your own client.

4/ The proof: every client gets an httpx transport that counts request and response bytes by host. Anything not sent to your model server lands in a separate counter. On screen it reads 0 bytes to AI providers.

5/ The cost: Whisper is not streaming, so STT starts after you stop talking. The GPU bills per hour, not per minute. And you run model servers now. The panel shows our stage times next to the cloud stack's.

6/ For real residency, self-host LiveKit and the worker in the same Canadian region and lock egress to the model server. The agent code doesn't change, only URLs.

7/ Call the line, report an ER visit, and watch it get flagged while the byte counter stays at zero: https://mahimai.ca/blog/private-voice-agent-self-hosted-healthcare
